# 2028 전공연계과목 상담

원본 PDF 11개(6개 대학, 295페이지)를 바탕으로 만든 로컬 웹 앱입니다. 원본 폴더는 변경하지 않습니다.

## 실행

현재 설치된 환경에서:

```sh
cd /Users/work/2026_teampl/admissions_2028/course-guide
zsh run.sh
```

접속: http://127.0.0.1:8768 (이미 실행 중이면 중복 실행하지 않습니다.)

포트 변경: `PORT=8769 zsh run.sh`

## 화면

- 질문하기: VectorRAG / GraphRAG / Text-to-SQL 선택, 대학 필터, 로컬 답변 모델 선택, 원문 PDF 페이지와 조회 데이터·실행 기록 확인.
- 과목 데이터: 대학, 계열/유형, 일반선택·진로선택, 학과·과목 검색과 페이지 이동.
- 원문 자료: 실제 PDF 미리보기와 열기. 데이터 내보내기는 전체 관계 테이블의 UTF-8 BOM CSV입니다.
- 최근 질문은 이 브라우저의 localStorage에만 최대 8개 저장합니다. 휴지통 버튼으로 삭제합니다.

## 설치 환경

macOS, Python 3.14(검증 환경), Node.js, Ollama, Xcode Command Line Tools의 `swiftc`가 필요합니다. macOS Vision OCR은 한국어/영어를 사용합니다. 이미지·깨진 글꼴 PDF를 OCR하며 클라우드 OCR은 호출하지 않습니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm ci
ollama pull gpt-oss:20b
ollama pull bge-m3
```

Ollama 앱 또는 `ollama serve`가 실행되어 있어야 합니다. 기본 대화 모델은 `gpt-oss:20b`, 임베딩은 한국어를 지원하는 `bge-m3:latest`입니다. 모델 파일 다운로드만 인터넷을 사용하고 질의·임베딩·OCR에는 외부 API를 사용하지 않습니다. JS와 글꼴도 로컬 제공됩니다.

`OLLAMA_URL`, `CHAT_MODEL`, `EMBED_MODEL` 환경변수로 설정할 수 있습니다. `OLLAMA_URL`을 원격 서버로 바꾸면 로컬 처리 보장이 없어집니다. 임베딩 모델을 바꾸면 재적재가 필요하며 실행 시에는 저장된 인덱스의 모델을 사용합니다. 큰 모델은 메모리 사용량과 응답 시간이 큽니다. 설치된 다른 대화 모델도 화면에서 선택할 수 있으나 답변 품질은 다를 수 있습니다.

## 적재 및 저장 구조

```sh
.venv/bin/python extract.py
.venv/bin/python catalog.py
.venv/bin/python ingest.py
```

- `../Admissions-and-Recommended-Courses/`: 입력 PDF. 한글 파일명은 NFC 정규화하며 실제 파일 경로는 별도로 보존.
- `data/raw/<sha256-prefix>.json`: 페이지 텍스트, 원문 표, OCR 위치·신뢰도. 파일 해시 캐시로 변경 문서만 다시 추출. `extract.py --force`는 강제 재추출.
- `data/catalog.json`: 정규화된 과목 관계 감사용 JSON.
- `data/current.json`: 현재 활성 인덱스 디렉터리 포인터.
- `data/index-*/admissions.sqlite3`: documents, pages, recommendations, graph_nodes, graph_edges.
- `data/index-*/vectors/`: 영속 로컬 Qdrant 벡터 DB.
- `data/index-*/graph.json`: NetworkX 방향성 지식그래프. 관계에도 원문 근거를 연결.
- `data/index-*/recommendations.csv`, `metadata.json`: 전체 데이터와 적재 통계.

과목 관계는 대학 / 계열·유형 / 모집단위 / 선택유형 / 과목 / 권장수준 / 원문 조건 / 비고 / 교육과정 / 학년도 / 원문 ID·페이지 / 추출 방식 / 검토 상태를 저장합니다. '중 N과목', '또는', 미지정을 보존합니다. 이수 조건은 원문의 전체 조건이므로 여러 선택유형에 걸칠 수 있습니다.

새 인덱스가 완성되고 건수 검증을 통과한 뒤 포인터를 교체합니다. 재적재 중 기존 서버는 기존 인덱스를 계속 사용하며, 완료 후 서버를 재시작해야 새 데이터를 읽습니다. 과거 인덱스는 자동 삭제하지 않습니다. `ingest.py`는 동시에 여러 번 실행하지 마세요. 한 인덱스는 단일 서버 프로세스로 엽니다(`--workers 1`).

## 세 검색 방식

| 방식 | 실제 내부 경로 |
|---|---|
| VectorRAG | 문서 페이지/표 행을 최대 650자·90자 중첩 청킹 → 로컬 bge-m3 임베딩 → Qdrant cosine 검색 → 검색 청크로 답변 생성. 표에는 헤더를 반복하고 수정 전 열 및 건국대 2015 안내는 제외. 복합 표/OCR은 검토된 문서 표현을 청크에 반영. 과목 질문은 가이드 페이지로 범위를 제한. |
| GraphRAG | 로컬 LLM의 개체 추출 → 대학·계열·모집단위·과목 노드 해석 → 방향성 그래프의 대학→계열→모집단위→권장관계→과목/근거 탐색 → 부분 그래프로 답변 생성. 단순 벡터 검색의 이름만 바꾼 경로가 아님. 과목에서 역방향 탐색도 가능. |
| Text-to-SQL | 로컬 LLM이 스키마·실제 값에 맞는 SQL 생성 → sqlglot 검증 → 대학 범위가 제한된 메모리 SQLite의 읽기 전용 SELECT → 실제 결과로 답변 생성. SQL과 결과를 화면에 노출. |

GraphRAG는 명시적인 관계 탐색형이며, 커뮤니티 요약 기반 Microsoft GraphRAG 패키지를 사용하는 것은 아닙니다. 별도 Neo4j 서버 없이 그래프 노드·관계 테이블 및 그래프 JSON으로 영속화합니다.

SQL은 단일 SELECT, 허용 테이블·함수만 사용합니다. SQLite authorizer, query_only, 명령 수 제한, 최대 200행을 함께 적용합니다. 집계 결과에 행별 출처가 없으면 집계 대상 문서임을 표시하며 직접 매칭한 출처처럼 제시하지 않습니다. 모델 컨텍스트에 들어가지 못한 결과가 있으면 부분 결과 경고를 표시합니다. 한 번에 한 질문을 처리하고 동시 요청은 429를 반환합니다.

## 대학별 추출 범위와 주의

- 연세대: 과목 가이드 2~3페이지. 병합 셀 복원. 자율선택과 과학 진로선택 3과목 이상 조건 유지.
- 중앙대: 과목 가이드 3페이지. 병합된 진로선택 셀 상속. 대안 조합과 2·3과목 이상 조건 유지.
- 경희대: 수정 안내 3~4페이지의 **2025.8월 변경 후 열**만 사용. 핵심/권장을 별도로 보존. 핵심은 지원자격 필수가 아님.
- 건국대: 이미지 안내 2페이지의 **2022 교육과정**만 사용. 단과대학·계열 안내를 개별 학과별 규정으로 확대하지 않음. OCR 로마 숫자 원본 대조.
- 부산대: 2026.6.1 2차 수정 가이드. 깨진 글꼴 대신 OCR을 사용하며 6개 행 영역의 모집단위와 이수 조건을 원본 대조. '관련 과목'은 하단 참고 범위로 확장하되 전체 이수를 요구하는 것으로 바꾸지 않음.
- 서울대: 시행계획 PDF 37~38페이지. 유형 1/2/3, 간호·치의학의 수학 대안, 의과대학의 진로과목 포함 조건 유지. 제2외국어/한문은 원문에서 유형을 통합 제시하므로 임의로 일반/진로에 배분하지 않음.

계열은 대학이 제시한 학문분야·유형을 우선 사용합니다. 부산대처럼 번호별로 과목을 묶은 표는 서비스용 분류(예: 물리·공학)이며 공식 모집계열 명칭이 아닙니다. '225개 모집단위·범위'에는 단과대학 전체, 자유전공, 미지정 범위도 포함되어 있어 개별 학과 수와 같지 않습니다.

현재 제공된 파일 구조에 맞춘 파서입니다. 모든 대학의 임의 신규 PDF를 자동으로 이해하는 범용 파서가 아닙니다. 건국대·부산대·서울대의 검토된 복합 규칙은 원문 SHA-256을 고정하여 문서가 바뀌면 재검토 없이 적용하지 않습니다. 다른 대학도 새 문서·개정본은 표 헤더와 테스트를 검토해야 합니다. `원본 대조`는 해당 표 규칙과 주요 오독을 대조한 상태이며, 1,162개 관계 전수 수작업 감수를 뜻하지 않습니다.

OCR·LLM 오류 가능성은 남아 있습니다. 최종 상담 및 지원 결정에는 원문과 최신 모집요강을 확인하세요. 검색 실패는 권장과목 미지정과 다릅니다.

## 검증

```sh
.venv/bin/python -m pytest -q
npm run check
npx playwright test
```

Playwright 검사는 실행 중인 `127.0.0.1:8768` 서버를 사용합니다. 첫 설치는 `npx playwright install chromium`이 필요합니다. 테스트는 운영 벡터 DB 잠금을 획득하지 않으므로 서버와 함께 실행할 수 있습니다. 실제 LLM 질의는 응답 내용의 변동이 있어 별도 `smoke.py`로 검사합니다.

```sh
.venv/bin/python smoke.py
```

화면/모델 요청은 루프백 주소에서만 제공됩니다. 사용자 인증이 없는 로컬 도구이므로 인터넷에 그대로 공개하지 마세요.
